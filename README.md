# H2Vent — OpenFOAM Hydrogen Dispersion Validation Cases

OpenFOAM v2406 case setups and the modified solver used for:

> Huang, C., Dahlbom, S., Gehandler, J., Arymbayeva, A. *Benchmarking Hydrogen Dispersion CFD
> Simulations Using OpenFOAM.* Submitted to Energies (MDPI), 2026.

Hydrogen dispersion in naturally ventilated enclosures is simulated with the compressible,
buoyancy-driven, multi-species solver `rhoReactingBuoyantFoam` (passive dispersion, no
combustion; species air + H₂) and validated against the two-vent enclosure experiments of
Bernard-Michel and Houssin-Agbomson (2017).

## Repository scope

This repository contains the **case setups** needed to reproduce the simulations reported in
the paper — mesh generation dictionaries and STL surfaces, initial and boundary conditions,
thermophysical and turbulence properties, and solver settings — together with the source code
of the modified solver used in the turbulent Schmidt number study. It does **not** include
solved field results or probe time series; these are regenerated by running the cases.

## Case directory naming

Directories follow `<enclosure>_<nozzle>_wall_H2_test_<N>`, e.g.
`1m3_27mm_wall_H2_test_55` = 1 m³ enclosure, 27 mm nozzle, internal test number 55.
The test numbers reflect the chronological order in which cases were run, not the design
parameters. The tables below map each case to its conditions and its role in the paper.

Unless stated otherwise, cases use the standard k–ε model, Sc_t = 1.0, the first-order Euler
time scheme and the production mesh.

## Repository contents

```
<case_dir>/
├── 0.orig/          # initial and boundary conditions (copied to 0/ by Allrun)
├── constant/        # STL surfaces, thermophysical and turbulence properties
├── system/          # blockMesh, snappyHexMesh, fvSchemes, fvSolution, decomposeParDict, ...
└── Allrun, Allclean # meshing and initialisation workflow

solver/rhoReactingBuoyantFoamSc/   # modified solver for the Sc_t study (GPL-3.0)
```

## Reproducing a case

```bash
cd <case_dir>
bash Allclean && bash Allrun
# copies 0.orig -> 0, then runs surfaceFeatureExtract, blockMesh, snappyHexMesh,
# topoSet, createPatch, checkMesh, renumberMesh, potentialFoam

# run the solver named in system/controlDict ("application"), e.g. in parallel:
decomposePar
mpirun -np <N> rhoReactingBuoyantFoam -parallel
```

The ceiling H₂ concentration and vertical profiles are written by the probe function objects
defined in `system/controlDict` to `postProcessing/`.

## Solver for the Sc_t study: `rhoReactingBuoyantFoamSc`

Source: `solver/rhoReactingBuoyantFoamSc/`. It is the OpenFOAM v2406
`rhoReactingBuoyantFoam` with one change: the species equation (`YEqnSc.H`) divides the
effective diffusivity by a turbulent Schmidt number,

    - fvm::laplacian(turbulence->muEff() / Sct, Yi)

instead of `- fvm::laplacian(turbulence->muEff(), Yi)`. `Sct` is read from the turbulence
model's coefficient dictionary in `constant/turbulenceProperties`, e.g.

    RAS
    {
        RASModel        kEpsilon;
        kEpsilonCoeffs  { Sct 0.7; }
    }

and defaults to 1.0, which reproduces the standard solver. All other source files are
identical to the v2406 originals.

Build (OpenFOAM v2406 environment sourced):

```bash
cd solver/rhoReactingBuoyantFoamSc
wmake        # installs to $FOAM_USER_APPBIN
```

## Experimental reference data

Experimental values used for validation are taken from Bernard-Michel, G., Houssin-Agbomson, D.
(2017), *Comparison of helium and hydrogen releases in 1 m³ and 2 m³ two vents enclosures:
Concentration measurements at different flow rates and for two diameters of injection nozzle*,
Int. J. Hydrogen Energy 42, 7542–7550, https://doi.org/10.1016/j.ijhydene.2016.05.217.
They are not redistributed in this repository.
